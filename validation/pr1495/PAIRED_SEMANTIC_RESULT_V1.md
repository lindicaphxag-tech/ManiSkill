## Design

Two immutable request distributions were frozen:

1. requests generated by current main;
2. requests generated by the composed repair.

Within each corpus, all four implementations received identical delta poses, controller bounds, episode identities, and within-episode order.

Inference unit: **episode**, not control call.

Bootstrap: episode-cluster bootstrap.

## Interpretation

The mechanism-level result is now:

[
L(R_1) > L(\varnothing),qquad
L(R_2) > L(\varnothing),qquad
L(R_1 \oplus R_2) \le L(\varnothing)
]

on **two independently generated frozen request distributions**.

The effect is not a consequence of treating thousands of temporally correlated control calls as independent samples: the uncertainty calculation resamples episodes.
