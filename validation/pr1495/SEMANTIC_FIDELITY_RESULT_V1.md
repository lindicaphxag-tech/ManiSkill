## Question

For delta-pose requests generated while replaying official
`PegInsertionSide-v1` demonstrations, how closely does the physical rotation
decoded by the production `PDEEPoseController` match the rotation requested at
the converter boundary?

The metric is SO(3) geodesic error between:

1. the desired rotation recovered from the inverse delta quaternion supplied to
   `delta_pose_to_pd_ee_delta`; and
2. the rotation realized after the converter output is passed through the
   production controller's `_clip_and_scale_action` and interpreted as XYZ
   Euler.

This is a direct semantic metric. It is not task-success, learned-policy
performance, or real-robot safety.

## Interpretation

This exposes a failure mode that task/API validity alone can hide:

- current main contains two locally inconsistent rotation semantics whose
  effects substantially compensate at the converter/controller boundary;
- correcting only the converter removes that compensation while leaving the
  controller sign fault, producing a large semantic regression;
- correcting only the controller exposes the converter representation fault;
- repairing both boundaries restores near-zero converter→controller semantic
  error.

The result therefore supports an **atomic repair** requirement for this
interaction: a locally correct patch is not necessarily a safe deployable unit
when another compensating semantic fault remains downstream.

## Important limitation

The four cells did **not** receive identical request sequences in this run.
Each implementation was measured on calls generated by its own replay, so
trajectory divergence changes both the number and distribution of requests.

Therefore this result is strong mechanism evidence but is not yet the final
causal estimate of the interaction magnitude.

A stricter follow-up is now frozen:

- capture one immutable request corpus from current main;
- capture one immutable request corpus from the composed repair;
- evaluate all four implementation cells offline on **exactly the same requests**
  within each corpus;
- bind each comparison to the corpus SHA-256;
- report paired effects and deterministic bootstrap confidence intervals.
