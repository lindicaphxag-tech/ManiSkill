# When Did My Robot Command Execute?
## Whole-History Public Observability and Privileged-State Economy Under Two Physically Ambiguous Executions

**Research manuscript v2.1 · 9 October 2026 · evidence-first technical draft, NOT peer reviewed or accepted.**

**Zhibo Zhang · Hangzhou Dianzi University.** Authorship and affiliation must be confirmed before submission. All original experiments reported below are owner-operated ManiSkill CPU PhysX, not real robot hardware, network-loss trials or independent external replication.

### Abstract

A frozen robot policy can become semantically incorrect during action-interface transfer even when it produces valid action vectors. The source policy may express increments relative to achieved end-effector pose, while the destination controller composes those increments from its last commanded target. An uncertain execution acknowledgement therefore hides a discrete controller-memory state, not merely the last command's delivery status. We ask whether public end-effector motion can identify an entire plausible native target history and remove the need to read a privileged commanded-target register. Our method propagates complete native position-and-orientation target candidates; an empirically calibrated, command-conditioned public XYZ response test selects an entire surviving SE(3) history only when it is uniquely compatible with the observed motion, otherwise spending one explicit target read. Earlier experiments showed conditional information savings but did not actually realize all four applied/held outcomes of two missing acknowledgements. We preregistered a new, truly seed-disjoint study of 64 frozen-PPO manipulation resets in which both native command executions are physically applied or held in all four combinations, and the second intended command is explicitly nonzero. Each faulted controller is charged the same additional known-delivered neutral observation step. In 576 independently stepped native PhysX controller instances across PullCube and StackCube, the whole-history observer completed 49/64 official tasks using 33 privileged target reads, compared with the same 49/64 tasks using 51 reads for a physically executed task-aware strong comparator and 64 reads for fixed-time readback. The observer publicly selected 31 entire target histories with zero observed wrong confident labels; the remaining 33 cases used an authoritative read. The experiment supports a 35.3% *observed reduction in privileged reads* at matched physical fault and neutral-control interventions, not statistical noninferiority, a task-success advantage, equal overall sensing cost, verified hardware safety or general VLA transfer.

**Keywords:** robot learning; action-interface semantics; latent execution history; uncertain acknowledgement; target-state observability; selective sensing; frozen-policy transfer.

## 1. Hidden command execution is a controller-state problem

A destination target-relative controller maintains a previously commanded target M_t distinct from the achieved physical end-effector pose x_t. With a typed native relative action u_t and uncertain native execution truth z_t, its target changes according to

\[
M_{t+1} =
\begin{cases}
F(M_t,u_t), & z_t=1,\\
M_t, & z_t=0.
\end{cases}
\]

Here F is an *already known and verified* native controller target recurrence. A missing acknowledgement leaves z_t hidden. Two such unknowns can yield up to four plausible target-pose histories, even if all commands were generated by the same unchanged frozen policy. Neither successful parsing of an action vector nor a well-tracked achieved pose proves which commanded target the destination's subsequent action will compose from.

The present work does **not** claim to invent discrete belief tracking, active observation or finite set-membership classification, which are already studied in ActionShift and ActionABI and other robotics literature. It isolates the semantics of **missing execution truth under a known target-relative controller** and tests whether public motion can sometimes replace a specific private target register read in a real closed-loop PPO simulator task.

## 2. Finite full-pose history identification with explicit abstention

The adapter preserves the set H_t of all currently possible native commanded target poses, each carrying position and quaternion from the actual known native recurrence. It never invents an orientation by fitting XYZ or falsely demands that *discarded* competing hypotheses share its orientation.

For each candidate i, given public achieved XYZ immediately before and after a known-delivered neutral target-delta step, the historical response model assumes

\[
y \approx x + \alpha (M_i^{xyz}-x)+e,\quad
\alpha\in[0,1],\quad \|e\|_2\le\epsilon_{\mathrm{task}}.
\]

The candidate's residual is the minimum distance from the measured after-step position to the line segment between the before-step achieved position and the candidate target position. Its task-dependent epsilon is calibrated on earlier, separately exposed data and remains frozen across all prospective tests. A public whole-history authorization requires *exactly one* compatible complete target candidate and every other candidate's residual to exceed epsilon plus a fixed 0.002 m margin. The selected candidate's preexisting complete position/quaternion is then used for action compilation; if this condition fails, the adapter pays for one explicitly logged private commanded-target read instead.

This is a conditional empirical observation model, not a physical certificate. In particular, contact, damping, different controller parameters or a changed observation time can invalidate its epsilon and produce confidently incorrect target histories. The source audit explicitly tests for wrong confident identifications against the genuine post-physics target state without exposing that audit-only value to the decision algorithm. The controller's belief and action branch are also required to invalidate together after any authoritative resynchronization: an earlier controlled study found that caching the old multi-history control branch after a read created a spurious apparent query-policy advantage.

## 3. Why the 2x2 physical falsifier was necessary

An original all-held two-ACK study had 64 distinct original reset states and 512 separately physically stepped comparison worlds. The public whole-history mechanism completed 58/64 frozen-PPO tasks using 39 controller-private reads versus 58/64 with 57 reads for a preregistered task-conditioned baseline, but the task generator always physically held both ambiguous commands. An always-assume-held zero-read method could exploit this protocol.

A later 64-state mixed-t2 truth experiment physically executed the first command on half the trials, while retaining a held second command; it observed 58/64 with 31 private reads against 58/64 with 58 for a strong task-aware comparator. That earlier mixed-t2 cohort reused 32 reset identities from an already preregistered full-pose survivor study. We have published this reset-identity overlap and do not treat the mixed-t2 result as 64 entirely independent previously unseen reset states.

A subsequent *truly seed-disjoint* mixed-first-ACK/held-second experiment on PullCube 1180001–1180032 and StackCube 1190001–1190032 repeated the original method without retuning: 57/64 official task completions using 33 reads, versus a task-aware strong comparator at 56/64 with 52. Despite resolving the seed-identity objection, the second ambiguous command was still always held. Calling execution of a **zero command** applied would not have made four physical target-memory truths. This motivates the present intervention instead of another same-fault sample extension.

## 4. Prospective new native PhysX four-truth experiment

### 4.1 Frozen original contract and physical truth

The new [pre-outcome preregistration](https://github.com/lindicaphxag-tech/ManiSkill/commit/554705d042fe886ee9365be560f0696ab7e1bd4c) was committed *before implementation of the new physical runner*, fixing fresh PullCube seeds **1340001–1340032** and StackCube seeds **1350001–1350032**. There are **8 trials of each true t2/t3 combination per task**, 16 for each combination across both tasks.

At time index t2 the original intended translated native policy action is physically applied or held; at t3 a **separately disclosed fixed nonzero native six-dimensional target increment (0.40, 0, 0, 0, 0, 0)** is actually applied or physically held. This native second pulse is deliberately *not* a general arbitrary PPO command, and it is not learned from the seed or a private state. The four physical truths (H,H), (H,A), (A,H) and (A,A) are selected by seed modulo four, invisible to the control decision. For any t3 event labeled applied, original source checks that the commanded controller target genuinely changed by more than 1e-4 in position or rotation; a held t3 must retain the target to the same tolerance. Merely assigning the word "applied" to a zero physical command cannot pass.

At t4 **every faulted comparison controller** actually dispatches one known-delivered native zero increment. It replaces one native source-PPO action opportunity and is explicitly counted as additional physical observation cost. The public method uses the achieved XYZ before and after this step to eliminate latent target candidates; at t5 it either commits to its unique complete candidate or spends one true private target-memory read. The fixed-read comparator pays at the same t5 time. This is one changed experimental protocol shared by all active comparator worlds, not an artificial replay that reuses old trajectories.

The released third-party PullCube/StackCube PPO weights are unchanged; the native action ABI and historical motion epsilon/2 mm gap are unchanged; no outcomes from these 64 seeds were used for training or retuning. Each source reset launches nine independently stepped native fault and baseline controller worlds (576 total genuine CPU PhysX controller worlds, not 576 trained policies, robot bodies or external investigators). All original failures are retained.

### 4.2 Actual official PPO task success and information-cost result

The [first complete 10/10 successful true native PhysX source run](https://github.com/lindicaphxag-tech/ManiSkill/actions/runs/37921809790) and its independent complete source auditor produced the following original full-denominator comparison. A second [hash-pinned source recomputation and five simulated-evidence tamper tests](https://github.com/lindicaphxag-tech/ManiSkill/actions/runs/37922340636) passed after that original execution. Full original JSON, each independent shard audit, the first and recomputed complete audits and SHA-256 hashes are in the [permanent 2x2 evidence archive](https://github.com/lindicaphxag-tech/ManiSkill/tree/research/two-by-two-real-nonzero-ack-physx-20261009/research/frozen_policy_transfer/evidence/true_two_by_two_nonzero_ack64_1340001_1350032).

| Original physical frozen PPO method | Official task completions | Private target reads |
|:--|--:|--:|
| **Public complete-history unique-or-one-read** | **49/64** | **33** |
| **Task-conditioned strong selective/fixed controller** | **49/64** | **51** |
| **Fixed-t5 authoritative reader** | **49/64** | **64** |

The new method and its strongest task-aware competitor had **identical paired binary task success on all 64 states**: 49 both successful, 15 both unsuccessful, no discordant outcomes. There is no observed task-success improvement and no statistical noninferiority proof. The actual private-state read cost was lower by 18/51 = **35.3%**, while public achieved-XYZ samples and one charged neutral controller action were additional real costs. The method publicly selected **31/64 complete target histories** with **zero observed wrong confident full-pose identifications**. It refused to infer in the remaining **33/64** and used one genuine authoritative read each; this does not bound future physical error probability.

## 5. Interpretation, novelty and specific unsupported extrapolations

The experimental result is a controller-private-state information-budget reduction under a precisely stated **four-truth physical native command protocol**, using a known target-relative action chart and a historically calibrated public-motion response model. The novelty is in how whole target-memory history selection is coupled to actual online frozen-PPO task control and an explicit abstain-or-read authority boundary; it is not a new general SE(3) observability theorem, first-ever active belief or an undisclosed target-state oracle.

ActionShift and ActionABI already develop action contract inference, belief adaptation and active probing. A convincing general robotics contribution now requires a genuinely new controller/robot family, strict equal-total-information and physical probing cost comparisons to such active-belief alternatives, independently attested motion uncertainty, and an outside researcher's new-seed source-level reproduction. No part of this work proves robust control under true dropped/reordered messages or contact-force perturbations.

Key remaining validity limits are **one Panda target-relative robot family, two frozen published PPO task checkpoints, source-known controller action semantics, one declared nonzero second pulse rather than arbitrary policy-native t3 actions, unchanged empirical response-envelope assumptions, additional charged neutral motion step, no camera-based VLA closed-loop task success, no physical hardware collision/torque safety, no third-party investigator run and no peer-reviewed paper acceptance**. The zero wrong confident source labels on only 31 author-operated positive decisions are finite observations, not a general safety certificate.

**Supported conclusion.** Complete controller-target execution histories can sometimes be disambiguated from public achieved motion under a known native action chart and empirically supported dynamics, reducing the need to inspect privileged commanded-target memory even when both unknown ACK commands genuinely may have executed. The existing study has established *conditional sensing-cost economy*, not task efficacy gains over correctly queried baselines, a universal observability guarantee or verified deployment safety.
