## Primary research question

Can public achieved end-effector motion and a *set of plausible controller target histories* replace some privileged controller target-pose readbacks following two unknown ACK events **without lowering native task completion**, when the comparison fixes the pre-decision physical history and removes post-decision algorithm implementation confounds?

Only reduction in **privileged target reads** is directly targeted; both experimental arms consume the same known-delivered neutral t4 probe, and the public arm additionally uses two publicly available achieved-position samples. Consequently no energy, elapsed-latency, sensing-overhead, real-network or real-hardware saving is claimed.

## Elementary identifiability result (a non-asymptotic statement, not a performance theorem)

Let `H` be the finite set of possible controller target histories generated by unacknowledged commands, and let `Y_h` denote the set of public achieved-motion observations consistent with candidate history `h` under a *specified observation/actuator uncertainty model*.

**Necessity:** If `Y_i ∩ Y_j` is nonempty for two histories with materially distinct target poses, no deterministic decision rule based on this public observation alone can correctly identify the target history under *both* possibilities: the same admissible observation would require conflicting outputs. A mandatory private read or abstention is then a defensible option.

**Sufficiency subject to a valid envelope:** If the observed public motion belongs to exactly one `Y_h` and the uncertainty envelopes cover all physically possible observations, a unique compatible history can be identified. Proof: all alternatives are excluded by nonmembership; coverage guarantees that the remaining candidate is the true history.

**Crucial empirical limitation:** The implemented public admissibility rule uses a calibration-derived positional residual threshold and an extra 2 mm margin. These are **empirical**, not verified conservative actuator-error bounds. Observed zero errors among twenty-one earlier authorized cases does **not** imply the sufficient-condition assumptions are established, nor does it prove safety. Under an illustrative independent identical-Bernoulli assumption only, zero errors in 21 admissions yields a one-sided 95% upper misidentification probability about **13.3%**; the actual collected trajectories need not satisfy the independence assumption.

This statement is useful because it separates *whether target history is observable* from *which classifier was used*. Its falsification is any verified accepted public history not matching the audit-only native controller target, or any model-envelope miss.

## Outcome decision and reporting contract

1. **Do not select seeds, margins or thresholds after seeing outcomes.** Use 64 resets from 1480001–1480032 and 1490001–1490032; do not mix in the previous original64.
2. **Audit source and execution.** Confirm both unknown ACK commands physically executed according to the pre-registered 2×2 schedule, all 576 worlds submitted, original per-shard data preserved, and common-prefix equality checked before the t5 decision.
3. **Audit common postquery compiler.** Record the actual source-native policy 7D proposal, prior single target belief, compiled 6D command and private read count per step for the public and fixed-read arms. Reject a run if any recorded compiled step deviates from the one implementation path.
4. **Report paired outcomes, not detached percentages.** Include task-stratified and four-ACK-truth-stratified paired success/loss, both-off/one-only contingency counts, private reads, authorized public histories, and audit-only wrong admissions. A one-success difference on 64 correlated resets is not evidence of a general task-success superiority claim.
5. **Preserve counterevidence.** A worse success result, one wrong confident history, or a source/prefix mismatch must remain visible in manuscript and artifact. A past control, [prospective Bayesian posterior 16-state comparator](https://github.com/lindicaphxag-tech/ManiSkill/actions/runs/37923604209), found *no* posterior-authorized histories over those sixteen resets; complexity alone does not establish a stronger method.

## Explicit nonclaims and highest-leverage external step

A green author-controlled GitHub Action does not constitute an investigator-selected **independent** reproduction. A 64-state synthetic ACK challenge does not establish physical network loss robustness, VLA task transfer, model generalization, hardware safety, statistical noninferiority, or community adoption. Those claims require a separate investigator-controlled checkout and reset distribution, preferably on a distinct controller/policy family. An independent party must publish their own original source evidence, not merely run the author's verification function on an author's saved JSON file.

The strongest contribution claim currently supportable, if the prospective experimental and audit gates pass, is narrow: **under matched physical-prefix and unified post-query compiler constraints, empirical public target-history identifiability sometimes reduces privileged controller target readbacks while preserving observed paired native task success in the tested workloads**. Generalization remains a separately falsifiable open question.
