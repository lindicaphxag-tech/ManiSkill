# Top-Tier Robotics Main-Conference Readiness Gates

**Date:** 2026-10-09. **Status:** research preprint with authentic simulation evidence; not yet an outstanding main-conference result, no acceptance claim.

## What we can say and prove

Primary same-compiler, same-command-prefix physical test: 64 new reset states, 576 native PhysX worlds, frozen third-party PPO, 53/64 exact same task successes, public-evidence 48 controller-private target reads versus matched fixed target-read 64, 16 confidently admitted histories, zero wrong confident observed **only in that source cohort**. Original physics archived with SHA hashes; reviewer source-only audit passed.

Crucial authentic negative: an independent same-public-XYZ 64 new-source study observed one wrong confident history and 53/64 successes for the original rule versus 54/64 from an ACK-specific Bayes-style comparator. A subsequent independent 64-state/640-world physical study tested an add-on 0.65 normalized residual score and found 54/64 outcomes for both original and add-on method, 41 versus 45 private target reads, zero wrong in BOTH on that new cohort, and two original trials missing fully matched t4 probe exposure (all 64 task results retained). The additive gate is **not** two independent witnesses: its score deterministically transforms existing XYZ residuals.

## Acceptance-critical unanswered questions

1. **New physics information, not score repackaging.** Can public achieved orientation SO(3), temporal motion, contact/slip, or a separately observed image channel distinguish execution histories when public XYZ response-model support fails? Count actual extra sensor information and controller actuation rather than claiming it is free. Existing code/results DO NOT already establish this.
2. **Reliability-aware action authority.** Does a source-calibrated support/abstention mechanism actually reduce wrong confident histories under genuinely new physical contact and controller response regimes, while retaining a worthwhile task/read/latency frontier? No global “zero-error” claim from a cohort with zero observed mistakes.
3. **Matched-budget active method.** An actual relevant active observation/identification baseline must have the same originally logged public observations, native probe steps, private controller getter entitlement and computational latency. The custom ACK-specific posterior comparator is NOT the full public ActionShift DualABI.
4. **Real second learned-policy/controller task transfer.** Existing SmolVLA LIBERO native 4+4 success (4/4 Task 1, 1/4 Task 0) is a valid no-fault task competency pilot, but robosuite OSC is achieved-EE-relative and does NOT provide ManiSkill accumulated-target history semantics. Mechanism-only xArm6 tests are not frozen-policy xArm6 task successes. First verify an appropriate control action chart and a task-competent checkpoint.
5. **Independent investigator evidence.** An outsider must actually choose their own never-used task resets in their own fork, run the native policy/control method, retain original errors and post original hashes. Self-owned Actions/source audits, even with authentic PhysX, do not prove external adoption.
6. **Full scientific statistics.** Preregister primary false-authorization and task outcomes, show paired task identities and confidence bounds; stratify actual t2/t3 AA/AH/HA/HH faults, task, prior geometry/contact and probe-censored originals. Never retrospectively pool distinct populations or condition on completed episodes only.
7. **Submission integrity.** A real anonymized main-paper file must be self-contained, cite ActionShift, conformal calibration and classic identifiability limits accurately, show professional source-derived vector figures, and comply with that conference's current page, references and anonymization rules.

A proposal that fails these gates may still produce a valuable mechanism/negative-findings paper. It must not be branded universally safe, VLA fault-resilient, or guaranteed conference accepted.
